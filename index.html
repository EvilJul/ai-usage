开始记录 AI 用量

还没有用量数据。点击上方「同步本机用量」，导入这台电脑上的 cc-switch 历史记录。

还没有收到采集端的数据。按下面三步连接采集端。

  1. 启动服务时配置 ingest token 文件。
  2. 在采集端运行 node --experimental-sqlite src/index.js init，填写 http://127.0.0.1:8787/v1/ingest 和同一个 token。
  3. 先运行 node --experimental-sqlite src/index.js scan，确认扫描通过，再运行 node --experimental-sqlite src/index.js backfill。

同一台 Mac 上使用时，可双击仓库里的「启动用量看板.command」，使用一键同步。
